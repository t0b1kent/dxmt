# MacRunner graphics · DXMT fork

**Current MacRunner component release: [HyperBridge DX9 1.1.1](https://github.com/t0b1kent/dxmt/releases/tag/v1.1.1), November 16, 2026.** [MacRunner application](https://github.com/t0b1kent/macrunner-app/releases/tag/v1.1.1) · [Release notes and current game status](https://github.com/t0b1kent/macrunner-app/blob/main/docs/RELEASE-1.1.1-EN.md) · [Corresponding graphics source](https://github.com/t0b1kent/dxmt/tree/v1.1.1).

The DX9 package contains MacRunner's experimental Direct3D 9 → Metal components for 32-bit Windows software, including the Gothic 3 work. It is a component package, not a standalone launcher. The application also selects separate experimental D3D10/11 and D3D12 paths. Gothic 3 starts in owner testing but has first-launch and Retina-input issues; current Elden Ring startup is under investigation. Historical game results do not certify the 1.1.1 package.

This is an unofficial MacRunner fork. The D3D12 and DX9 work is separate from upstream DXMT and is not endorsed by or submitted to upstream. Upstream notices and licenses are retained.

## Upstream project description

A Metal-based translation layer for Direct3D 11 and 10 which allows running 3D applications on macOS using Wine.

For the current status of the project, please refer to the [project wiki](https://github.com/3Shain/dxmt/wiki).

The most recent development builds can be found [here](https://github.com/3Shain/dxmt/actions).
