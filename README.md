# MacRunner graphics · DXMT fork

**Current component: [HyperBridge DX9 1.1.3](https://github.com/t0b1kent/dxmt/releases/tag/v1.1.3).** [MacRunner application](https://github.com/t0b1kent/macrunner-app/releases/tag/v1.1.3) · [Release notes](https://github.com/t0b1kent/macrunner-app/blob/main/docs/RELEASE-1.1.3-EN.md) · [DX9 PE source](https://github.com/t0b1kent/dxmt/tree/v1.1.3).

HyperBridge DX9 1.1.3 switches display modes for 32-bit Direct3D 9 fullscreen and recovers Metal pipeline archives when serialization fails. BUILDINFO identifies the separate PE and macOS source revisions used in the release.

This is an unofficial MacRunner fork; the D3D12 and DX9 work is separate from and not endorsed by upstream DXMT. Original licenses and notices are retained.

## Upstream project description

A Metal-based translation layer for Direct3D 11 and 10 which allows running 3D applications on macOS using Wine.

For the current status of the project, please refer to the [project wiki](https://github.com/3Shain/dxmt/wiki).

The most recent development builds can be found [here](https://github.com/3Shain/dxmt/actions).
