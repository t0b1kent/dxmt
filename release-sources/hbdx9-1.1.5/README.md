# HBDX9 source for MacRunner 1.1.5

This directory contains the accepted graphics compilation inputs with the 32-bit HBDX9 implementation used in MacRunner 1.1.5. The release enables early query flushing and query prediction. The Direct3D 9 implementation is in [src/hbdx9/d3d9_shim.cpp](src/hbdx9/d3d9_shim.cpp).

The [MacRunner 1.1.4 HBDX9 tag](https://github.com/t0b1kent/dxmt/tree/v1.1.4/src/hbdx9) retains the earlier fullscreen mode source and its build recipe. See [COPYING.LIB](COPYING.LIB) and the component license notices.
